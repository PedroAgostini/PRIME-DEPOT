# Prime Depot

Site da Prime Depot Global Enterprises LLC: importadora direta de PVC celular (trim boards e sheets) em Hyde Park, MA.

- HTML, CSS e JavaScript puros, sem framework e sem build.
- Páginas: `index.html` (home com catálogo e carrinho de orçamento), `checkout.html`, `order-success.html`, `404.html`.
- Fotos, fontes, logos e ícones em `assets/`.

## Rodar localmente

```bash
npx http-server -p 5577 -c-1
```

Abra http://127.0.0.1:5577
